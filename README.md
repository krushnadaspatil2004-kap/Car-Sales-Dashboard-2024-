# Car-Sales-Dashboard-2024-
Recommended structure and order
1. Project Title / Headline

🚗 Car Sales Analysis Dashboard | Power BI

 2. Short Description / Purpose
This project analyzes car sales data to identify sales trends, revenue performance, profit generation, customer behavior, and vehicle preferences. The dashboard provides interactive insights to help businesses make data-driven decisions and improve sales performance.

3. Tech Stack

📊 Power BI – Dashboard development & visualization
🧹 Power Query – Data cleaning & transformation
📐 DAX – Measures & calculations
📗 Microsoft Excel – Data source
📁 File Formats –  .pbix for development & .png for dashboard preview

4. Data Source
   
Kaggle – Car Sales Dataset
Contains 10,000 car sales records with details on date, brand, model, fuel type, sales, revenue, discount, and profit.

5. Business Problem

The business needs to identify sales trends, top-performing brands and car models, revenue and profit performance, fuel-type preferences, and regional sales to support data-driven decisions.

6. Features / Highlights

* 📊 Total Sales and Revenue KPIs
* 💰 Profit Analysis
* 🚗 Brand and Model Performance
* 📈 Monthly Sales Trends
* 🌍 Region and Country Analysis
* ⛽ Fuel Type Analysis
* ⚙️ Transmission Analysis
* 🏷️ Discount Analysis
* 🔎 Interactive Filters and Slicers
* 📌 Top-performing Cars and Brands
* 📅 Time-based Sales Analysis
